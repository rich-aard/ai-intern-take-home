# AI Intern Take-Home

Python scripts for ticket cleaning and basic NLP (Task 1), a public API client with error handling (Task 2), and written answers in `ANSWERS.md` (Part 3).

## Python Version

3.12

## Setup

### Create a virtual environment

```
python -m venv .venv
```

- Optional using uv:

```
uv venv .venv --python=3.12
```

### Activate:

- Windows (PowerShell): `.venv\Scripts\Activate.ps1`
- Windows (CMD): `.venv\Scripts\activate`
- macOS/Linux: `source .venv/bin/activate`

If PowerShell blocks the activation script with an execution policy error, run this once, then activate again:

```
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

### Install Dependencies

```
pip install -r requirements.txt
```

## Run scripts:

- For task1:

```
python task1_nlp_cleaner.py
```

- For task2:

```
python task2_api_client.py
```

## Assumptions and decisions

- Hyphenated words like Wi-Fi are split, so Wi-Fi becomes wi and fi.
- Stemmer used: Snowball Stemmer. So, keywords and saved tokens generated in preprocess_text are stems.
- The stop word list is the one given in the task brief.
- Fallback documents use negative ids so they can't collide with real ones.

## Verification and challenges

### Manual Verification

The scripts were tested manually by running them and checking their outputs. No automated test scripts are included in the repository.

**Task 1 (`task1_nlp_cleaner.py`)**

- Verified duplicate removal, handling of `None` and whitespace-only queries, HTML removal, category counts, keyword frequencies, and JSON output.

**Task 2 (`task2_api_client.py`)**

- Normal API request: returned 5 documents with the expected fields.
- Invalid endpoint: HTTP 404 was logged and fallback documents were returned.
- Invalid domain and offline network: connection errors were logged and fallback documents were returned without crashing.
- Timeout: temporarily setting the timeout to 0.001 seconds triggered the timeout handler and returned fallback documents.

### Challenges

- **Stemming vs. lemmatization:** I initially considered the WordNet lemmatizer, but it requires downloading WordNet data and using POS tags for more accurate lemmatization. I chose the Snowball stemmer instead. Stems aren't always real words (`updat`), which is fine for keyword counting.
- **Exception handling:** Specific `requests` exceptions are handled before the general `RequestException`. Since some exceptions inherit from multiple exception classes, the order of exception handlers matters. All request failures return the same fallback documents.
- **Tied keyword counts:** Only `vpn` and `day` appear twice, so ranks 3 to 5 are ties broken by first appearance.
